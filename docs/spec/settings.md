# Settings

This page covers every setting on Relay's **Settings** page, its default and its effect, what happens when the settings file is damaged, and the first run's screens.
Rules are numbered SET-n. Cite them in tests and PRs.

## The Settings page

- **SET-1** **Settings** in the Library's top bar opens Settings, one of the main window's three places (see [the window](windows.md)).
- **SET-2** Its side bar has five sections: **Recording**, **Keys**, **Window**, **Appearance** and **Sound**.
- **SET-3** Settings are Relay's own: they apply to every macro.
- **SET-4** A setting saves as soon as it's changed.
- **SET-5** How a macro plays (repeat, speed, data file, *Vary timing*, *Stop on key*, *Clicks land*) isn't a setting: it belongs to the macro, in the editor's **Macro** tab under **Play options**. See [Playback](playback.md).

## Recording

- **SET-6** The Recording settings apply to every new recording. What each one leaves in or out of a recording: see [Recording](recording.md).

| Rule | Setting | Default | Effect |
| --- | --- | --- | --- |
| **SET-7** | **Capture the mouse path** | On | Records the cursor's movement between clicks. Off records only where the clicks were, and playback jumps straight there. |
| **SET-8** | **Capture keystrokes** | On | Records the keyboard. Off records the mouse only. |
| **SET-9** | **Screenshot** | On | Saves a picture of the screen as recording starts, for the preview. It's kept on this PC only, never in exports. |
| **SET-10** | **Count down 3, 2, 1** | On | Counts down before recording starts. Off starts recording the moment the record key is pressed. |
| **SET-11** | **Esc stops recording** | On | <kbd>Esc</kbd> stops the recording. Off, <kbd>Esc</kbd> is recorded like any key, and the recording stops with the record key or the player's **■**. |
| **SET-12** | **Ignore simulated input** | On | Leaves out input generated by other programs. Remote Desktop and KVM tools (such as Synergy or Barrier) deliver the user's real typing as simulated input, so with this on, that input is missing from the recording. |

- **SET-13** Whether the window steps aside while recording is a Window setting: **Hide the window while recording** (SET-16).

## Keys

- **SET-14** The **Keys** section sets Relay's global keys, **Record**, **Play / pause**, **Show the player** and **Stop everything**, and lists **Stop** as <kbd>Esc</kbd>, fixed. Their defaults (new install and upgrade), how they're set, **None**, refusals and warnings: see [Relay's keys and shortcuts](keys.md).

## Window

| Rule | Setting | Default | Effect |
| --- | --- | --- | --- |
| **SET-15** | **Keep the player on top** | Always | When the [player](windows.md) floats above other windows: **Always**, **While working** (while recording or playing) or **Never**. The main window itself is never on top. |
| **SET-16** | **Hide the window while recording** | On | The window steps aside while recording and the player shows instead, so Relay never covers what's recorded. Off, the window stays where it is and the player doesn't show. |
| **SET-17** | **Hide the window while playing** | Off | On, the window steps aside during playback and the player shows; the window comes back when the playback ends. Off, the window stays where it is, behind the user's apps, so the steps can be watched. |
| **SET-18** | **Close to the tray** | On | The window's close button and <kbd>Alt</kbd>+<kbd>F4</kbd> hide Relay to the tray, and hotkeys and triggers keep running. Off, they quit Relay. |
| **SET-19** | **Start with Windows** | Off | Starts Relay hidden in the tray when the user signs in, so triggers run without opening it. See [Start with Windows](windows.md). |

## Appearance

| Rule | Setting | Default | Effect |
| --- | --- | --- | --- |
| **SET-20** | **Theme** | Like Windows | **Like Windows** (light or dark, as Windows' app mode), **Light** or **Dark** |
| **SET-21** | **Frosted glass** | On for Windows 11, off for Windows 10 | The desktop shows through the window, blurred. It's off by default on Windows 10, where it can slow down moving the window. |
| **SET-22** | **Spacing** | Comfortable | How much room the controls take: **Compact**, **Comfortable** or **Large** |
| **SET-23** | **Text size** | 100% | **100%**, **125%**, **150%** or **200%**. Everything grows with it, the window too. |
| **SET-24** | **Player size** | Compact | **Compact** (600 × 64) or **Large** (760 × 88) |
| **SET-25** | **Reduce motion** | Like Windows | **Like Windows** follows Windows' *Animation effects*; **Always** turns Relay's animations off. |
| **SET-26** | **Show click labels** | On | Labels next to the numbered clicks in the preview: a selected click shows its label next to its number. See [the view](view.md). |
| **SET-27** | **Mouse path** | Whole path | **Whole path** draws the whole path in the preview. **Played part** draws only the part already played. |

- **SET-28** With Windows' transparency effects off, Relay is solid and the **Frosted glass** switch is off.

## Sound

| Rule | Setting | Default | Effect |
| --- | --- | --- | --- |
| **SET-29** | **Sounds** | Off | Short clicks when recording starts and stops, a tick for each step recorded, and a sound when a macro finishes or fails |
| **SET-30** | **Try them** | | **Record**, **Stop**, **Done** and **Error** each play their sound, with **Sounds** on. |

- **SET-31** The sounds are quiet, and Windows' volume applies.
- **SET-32** Every sound comes with words on screen, never instead of them.

## The settings file

- **SET-33** Settings are kept in `settings.json`, in Relay's data folder (see [Installing, files and logs](install.md)). *Start with Windows* isn't stored there: it's an entry in the *Run* list of the user's Windows account.
- **SET-34** `settings.json` is read setting by setting: an unknown field is ignored, and a missing one takes its default without losing the others.
- **SET-35** A setting with a value Relay doesn't understand (such as `"keep_on_top": "sometimes"`, `"text_size": 110`, or a value from a newer Relay) goes back to its default, and the others are kept. The original file is set aside as `settings.json.bad`, the recovered settings are saved, and Relay says so: *… had values Relay doesn't understand; the setting “text_size” is back to the default (the file was moved to …)*, naming each setting reset.
- **SET-36** A `settings.json` that isn't JSON, or isn't a settings file, is set aside as `settings.json.bad` the same way, and every setting goes back to its default, which Relay says (*… every setting is back to its default*).
- **SET-37** A `settings.json` that exists but can't be read (locked by another program, say) is never overwritten: Relay says *… couldn't be read (…). Relay uses the default settings until it restarts, and leaves the file as it is.*
- **SET-38** A setting changed while it can't be saved still applies for the rest of the run, and Relay says *Couldn't save the change: …. It's kept until you quit.*

## The first run

- **SET-39** On a new install, Relay's window opens near the bottom of the main screen and starts with three short screens.
- **SET-40** **Skip** on the first screen, or **Later** on the last, goes straight to Relay.
- **SET-41** Screen 1, *Do it once. Relay does it again.*, says what Relay does: record once, play back whenever the user likes. It says Relay never connects to the internet and macros stay on this PC.
- **SET-42** Screen 2, **Your keys**, offers three choices for the keys that record and play from any app, without opening Relay:

| Rule | Choice | Record | Play / pause | Says it's good for |
| --- | --- | --- | --- | --- |
| **SET-43** | **Ctrl + Shift + F9 and Ctrl + Shift + F10** (recommended, chosen at first) | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F9</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F10</kbd> | Other apps keep <kbd>F9</kbd> and <kbd>F10</kbd> |
| **SET-44** | **F9 and F10** | <kbd>F9</kbd> | <kbd>F10</kbd> | One key each. Excel, Word and debuggers lose <kbd>F9</kbd> and <kbd>F10</kbd> while Relay runs. |
| **SET-45** | **I'll choose my own** | | | Keyboards without F keys. Relay opens **Settings → Keys** when the first run ends. |

- **SET-46** The keys screen also says how to stop: <kbd>Esc</kbd>, the player's **■**, or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Backspace</kbd> to stop everything at once (see [the kill switch](playback.md#the-kill-switch)).
- **SET-47** Screen 3, **Your first macro**, has **Record now**, which starts a recording right away.
- **SET-48** Every key chosen on the first run can be changed later in **Settings → Keys**.
- **SET-49** A data folder an older Relay used (it has `settings.json`, `library.json` or a `macros` folder) is an upgrade: instead of the three screens, Relay shows the keys screen once, with **Done**. Upgraders keep their keys (see [Relay's keys and shortcuts](keys.md)).
- **SET-50** On an upgrade, the keys screen offers **Use Ctrl + Alt + Backspace** for the kill switch, since Remote Desktop takes <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>End</kbd> for itself.
- **SET-51** After the first run, Relay opens on the Library, or straight on the user's macro while it's the only one. The empty Library: see [Library and Activity](library.md).
