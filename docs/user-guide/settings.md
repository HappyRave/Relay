## Recording settings

| Setting | What it does |
| --- | --- |
| **Capture the mouse path** | Records cursor moves between clicks. On by default. |
| **Capture keystrokes** | Records the keyboard. On by default. |
| **Screenshot** | Keeps a picture of the screen for the preview. On by default. |
| **Count down 3, 2, 1** | Counts down before recording. On by default. |
| **Esc stops recording** | Pressing <kbd>Esc</kbd> stops a recording. On by default. Read [Record the Esc key](record.md#record-the-esc-key). |
| **Ignore simulated input** | Skips input other programs send. On by default. Read [Record over Remote Desktop](remote-desktop.md#record-over-remote-desktop). |

More detail: [Settings: recording](../spec/settings.md#recording)

## Window settings

| Setting | What it does |
| --- | --- |
| **Keep the player on top** | Keeps the [player](glossary.md#player) in front: **Always** (default), **While working** or **Never**. **While working** means while Relay records or plays. |
| **Hide the window while recording** | Shows only the player while you record. On by default. |
| **Hide the window while playing** | Shows only the player while a macro plays. Off by default. |
| **Close to the tray** | Keeps Relay running in the [tray](glossary.md#tray) when you close the window. Triggers still work. On by default. |
| **Start with Windows** | Starts Relay in the tray when you sign in. Off by default. |

More detail: [Settings: window](../spec/settings.md#window)

## Appearance settings

For the sizes, read [Make the text and the player bigger](accessibility.md#make-the-text-and-the-player-bigger).

| Setting | What it does |
| --- | --- |
| **Theme** | Colors: **Like Windows** (default), **Light** or **Dark**. The player follows it. |
| **Frosted glass** | Blurs the desktop behind the window. On by default on Windows 11. |
| **Spacing** | Space around the controls: **Compact**, **Comfortable** (default) or **Large**. |
| **Text size** | **100%** (default), **125%**, **150%** or **200%**. The player grows with it, up to 150%. |
| **Player size** | **Compact** (default) or **Large**. |
| **Reduce motion** | **Like Windows** (default) follows Windows. **Always** turns off Relay's animations. |
| **Show click labels** | Labels the selected click in the preview. On by default. |
| **Mouse path** | What the preview draws: **Whole path** (default) or **Played part**. |

More detail: [Settings: appearance](../spec/settings.md#appearance)

## Sound settings

**Sounds** plays short sounds when Relay records and when a macro ends. Off by default. Read [Hear when recording starts and stops](accessibility.md#hear-when-recording-starts-and-stops).

More detail: [Settings: sound](../spec/settings.md#sound)

## Play options are per macro

Each macro has its own play options: **Repeat**, **Speed**, **Vary timing** and **Stop on key**. Read [Repeat a macro or loop it forever](play.md#repeat-a-macro-or-loop-it-forever).
